Inventory Management System

A console-based Inventory Management System developed to manage product records and maintain accurate stock information efficiently.

Features
Add new products
View all products
Search products
Update product details
Delete products
Track stock quantities
Identify low-stock products
Simple menu-driven console interface
Tech Stack
Language: Java
Concepts: OOP, Collections, Exception Handling, File Handling
Interface: Console / Command Line

How It Works

The system maintains a collection of products, where each product contains information such as:

Product ID
Product Name
Category
Price
Quantity

Users interact with the system through a menu-driven console interface to perform inventory operations.
